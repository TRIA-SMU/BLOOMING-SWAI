# 도전 요인 분석

- 최신 Figma Make ZIP의 분석 조건, 요약 카드, 비교 막대, 준비 항목, 관련 경험 배치를 사용한다.
- 홈의 ‘내 도전 분석하기’와 헤더 메뉴에서 진입한다. `/#analysis` 직접 접속과 뒤로가기를 지원한다.
- `GET /api/posts/analysis?challengeType=...&keyword=...`의 실제 값만 표시한다. 태그·도전 유형은 글쓰기와 동일한 서버 enum을 사용한다.
- 서버에 없는 준비 기간·지원 분야 필터, 임의의 준비 기간 및 본문 미리보기, 예시 데이터 표시는 제외한다.
- 실패·중단 건수는 서버가 합산한 failureCount다. 요인별 비율의 분모는 결과별 전체 기록 수다. 각 결과가 5건 미만이면 비율 표시를 생략하고 현재 언급 건수를 안내한다.
- 관련 경험은 서버가 반환한 대표 글 최대 3개다. 요인 선택은 이 대표 글 안에서 태그를 필터링한다. 전체 태그별 게시판 조회 API로 동작하는 것은 아니다.
- 준비 항목은 태그별 고정 행동 문장을 사용자가 선택·수정하는 방식이다. AI가 만든 결과로 표시하지 않는다. 선택한 문장은 `POST /api/checklist/bulk`에 `source: INSIGHT`로 저장한다. 해당 결과가 5건 미만이면 그 결과의 준비 항목 제안을 생략한다.
- 저장에는 로그인 확인이 필요하다. 성공 응답 후에만 ‘담기 완료’로 표시하며, 실패하면 입력을 유지한다. 같은 화면의 저장한 항목은 재전송하지 않는다. 서버에는 중복 방지 키가 없어 재분석·새로고침 후 같은 문장을 다시 담으면 별도 항목으로 저장될 수 있다.
- ‘체크리스트에서 관리’로 체크리스트 전체 관리 화면에 이동한다. 외부 구글 인증 이동 또는 새로고침 시 아직 담지 않은 문장은 유지되지 않는다.
- 조건 변경·화면 이탈 시 조회 요청을 취소한다. 로딩·오류·재시도·검색 0건·기록 부족 상태를 제공한다.

검증:

```powershell
npm run build
npm run lint
node --experimental-strip-types --test tests/*.test.mjs
node --experimental-strip-types scripts/verify-analysis-api.mjs
```

마지막 명령은 localhost:8080의 개발용 백엔드에서 수행한다. 분석의 실제 비율·건수, 0건 검색, INSIGHT 저장을 확인하고 스크립트가 생성한 체크리스트 항목만 삭제한다.
